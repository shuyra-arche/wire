left unchanged as history. This stage narrows the crate to a compatibility
facade over the canonical owner package; nothing above is rewritten.

  <https://github.com/shuyra-arche/kernel.git>, pinned to the full Kernel SHA
  `a9986c82127cf25183bf5c30e7d42e4a9376b734`. That package is now the single
  canonical byte-codec definition; this repository holds no second copy.
